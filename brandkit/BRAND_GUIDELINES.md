# BRAND GUIDELINES

## Logo Usage
- Use the provided SVG logo files for all print and vector use.
- Use the PNG exports for raster contexts; prefer the highest resolution available.
- Do not alter the logo proportions.
- Do not change logo colors except where a monochrome white or black variant is explicitly provided.

## Clear Space
- Maintain a minimum clear space equal to the height of the logo's uppercase letter around the logo.
- Do not place other elements within this clear space.

## Color Tokens
- --color-primary: #7c4dff (Lavender Accent)
- --color-text: #1f2937
- --color-bg: #ffffff
- Provide tints and shades as needed.

## Typography
- Heading: "Source Serif 4" or fallback serif, sizes: H1 48px, H2 36px, H3 24px
- Body: "Inter" or fallback system sans-serif, sizes: 16px (base), 20px (lead)

## File Formats Provided
- SVG: Vector logos (use for print, scaling)
- PNG: Raster exports at multiple sizes (web/app icons)
- ICO: favicon multi-resolution file
- site.webmanifest: Web manifest for PWA usage
